# 卫星成图计算说明

> 面向产品、研发和评审。用尽量少的术语解释：一颗卫星从 TLE 到“这张图能不能拍、覆盖率是多少”的完整过程，以及当前 task1 的“面积覆盖”口径和新加的可执行性规则。

## 0. 一句话理解

卫星成图不是“卫星拍一张照片”，而是：

**在给定时间窗内，从卫星池里挑几颗星，让它们扫过的条带尽量覆盖目标区域；再把每次条带按时间拼起来，算面积、时间、重访和缺口。**

- 卫星像一台**移动的扫描仪**，沿轨道飞，地面留下一条条带。
- 目标区域切成 **5 km 网格**，像棋盘。
- 一次过境只扫到棋盘的一部分；多次过境的并集才是“累计覆盖”。
- **累计覆盖**和**单景覆盖**是两件事：前者可以跨几天拼接，后者要求同一时刻/同一场景。

## 1. 输入

| 输入 | 说明 |
|---|---|
| TLE/OMM | 卫星轨道根数；用 SGP4 推算位置。TLE 越旧，误差越大（约 1 km/天） |
| 卫星与传感器 | 光学/高光谱/SAR；分辨率、幅宽、是否公开、是否 LEO |
| 目标区域 AOI | 省/市/区县 adcode，或手绘 WKT 多边形；只支持浙江省内 |
| 时间窗 | 开始时间 + 窗口长度（小时）；task1 可自动从当前窗口扩到 72h / 7 天（168h） |
| 目标 | 面积覆盖率目标（task1/task2）；时间覆盖率/重访/ART（其他任务） |
| 约束 | 最大分辨率、星下点/目标指向、云量过滤、太阳高度、最小仰角 |

## 2. 计算流程（七步）

### 第一步：TLE 与轨道

- 读每颗星最新 TLE，检查年龄：>72h 标 degraded，全部候选 >7 天拒绝计算。
- 用 SGP4 在时间窗内逐步长推位置；步长默认 10 秒。
- 得到每颗星在“什么时刻、什么经纬高”。

### 第二步：过境/访问窗口

对每颗星、每个网格：

- 计算卫星到网格代表点的仰角；低于 **10°** 的时段不算成像访问。
- 光学/高光谱再看**太阳高度**：低于 **10°** 的时段直接剔除（夜间不能可见光成像）。
- 云量：在 AOI 内取 3×3 个采样点，每个窗口用离它最近的采样点的逐小时 `cloud_cover`；超过阈值（默认 70%）剔除。
- 连续满足条件的时段就是一个 **AccessWindow**（访问窗口）；一个窗口通常几分钟。

> 这一步决定“有没有窗口”。如果窗口全被太阳/云量/仰角剔除，后面的覆盖率再高也没有执行意义。

### 第三步：网格化与面积

- 把 AOI 按 5 km 切成网格；每个网格有真实面积（边界格会小一些）。
- 每个网格记录：被哪些卫星、哪些窗口、覆盖了多长时间。
- 面积统计用网格真实面积加权，不是简单数格子。

### 第四步：算指标

| 指标 | 含义 | 直观解释 |
|---|---|---|
| 单格时间覆盖率 | 该格被覆盖时长 / 窗口总时长 | 这一格在 72h 里被看了百分之几的时间 |
| 累计面积覆盖 | 至少被看过一次的面积 / 总面积 | 多次过境拼起来，能盖住多少地 |
| 达标面积 | 达到时间覆盖率阈值的面积占比 | 只有“看得够久”的格子才算达标 |
| 最大瞬时覆盖 | 某一时刻同时覆盖的最大面积占比 | 单景最多能拍多宽 |
| 同时覆盖时间 | 同一时刻覆盖面积达到目标面积的时间占比 | 有没有“一张完整图” |
| MRT | 最大重访间隔 | 最久多久没再看同一格 |
| ART | 平均重访间隔 | 平均多久看一次 |
| 薄弱区 | 未达标/未覆盖网格的连通片 | 缺口在哪、连成多大一片 |

**关键区别：**

- `累计面积覆盖 81.7%` ≠ `单景 81.7%`。
- 81.7% 可能是两次过境隔 61 小时拼出来的；最大瞬时只有 73.4%。
- 报告里的“面积目标”是面积占比；“单格时间阈值”是每格要覆盖多久，两者不是一回事。

### 第五步：选星/优化

五个任务：

| 任务 | 问的问题 | 当前口径 |
|---|---|---|
| task1 最少星达到覆盖率 | 达到面积目标最少要几颗 | 面积至少成像一次；面积目标由用户填（默认 90%），不看单格时间阈值 |
| task2 最少星达到重访 | 给定 P95 重访，最少几颗 | 需要 MRT 目标和面积目标 |
| task3 给定星数最大化达标面积 | N 颗星最多能达标多少面积 | 需要 N、单格时间覆盖率阈值 |
| task4 给定星数最小化面积分位 MRT | N 颗星让面积分位 MRT 最小 | 需要 N、面积分位 |
| task5 给定星数最小化 ART | N 颗星让平均重访最小 | 需要 N |

task1 的“最少星”是**集合覆盖**问题：每颗星能覆盖一组网格，选最少的星覆盖目标面积。引擎用 ILP/贪心求解，结果会标 `proven_optimal` 或 `infeasible_heuristic`。

### 第六步：生成报告

报告包含：

1. 卫星构成：选中星、传感器、分辨率、幅宽、过境次数。
2. 覆盖与回放：网格首次被哪颗星覆盖；时间轴回放。
3. 过境窗口：每次过境的起止、时长、平均/最大覆盖。
4. 口径与精度：TLE 年龄、云量、太阳高度、复现指纹。
5. 薄弱区：未覆盖连通片（面积、网格数、经纬范围）。

### 第七步：回放与百分比

- 回放右侧的 `时间进度` 是**播放到第几帧/总帧数**，到最后一帧是 **100%**。
- 它不是覆盖率；覆盖率看标题的“达标面积”和首屏指标。
- 之前 33f46 显示 80.8%，是因为代码用了 `已覆盖网格数 / 总网格数`（632/782=80.8%），而标题 81.7% 是**面积加权**。两者口径不同；现在回放改为时间进度，最后一帧 100%，不再与 81.7 混在一起。

## 3. 当前 task1 的准确表述

task1 现在回答的是：

> **在 72 小时窗口内，至少成像一次的面积达到 X%（默认 90%），最少需要几颗星？**

它**不回答**：

- 单景能不能达到 X%；
- 这些过境是不是白天、云量是否可用；
- 多次过境之间隔多久、能不能拼成一张图。

所以报告首屏现在明确写“**面积为窗口内累计并集，不是单景**”。如果要执行，必须再过太阳/云量/时相一致性门禁。

## 4. 新加的可执行性规则（P0/P1/P2）

### P0：先判断“能不能拍”

1. **最小仰角 10°**：低于 10° 的访问不计入成像。
2. **光学太阳高度 >10°**：夜间窗口直接剔除。
3. **云量多点**：AOI 内 3×3 采样，逐窗口取最近点，不再用行政质心单点。
4. **TLE 新鲜度**：>72h 标 degraded；全部 >7 天拒绝；优先用当前同步的 TLE。
5. **先重算再执行**：如果加太阳/仰角/云量后 `feasible=false`，不要下发成像任务。

### P1：把“覆盖”与“成图”分开

- task1 自动扩窗：当前窗口 → 72h → 168h，达到目标即停；7 天仍不达标就返回最后一次并标注上限。

1. 报告明确“72h 累计并集，不是单景”。
2. task1/task2 的面积目标由用户填写，不再写死 90%。
3. 薄弱区按**连通片**聚合（面积、网格数、经纬范围），不只列 10 个单格。
4. 卫星按**边际贡献**排序，不按选中顺序；报告增加“最大瞬时”列。
5. task1 报告不展示时间覆盖率和面积加权 MRT；需要看成图质量时，看最大瞬时、时相差、薄弱区和过境窗口。
6. 回放显示时间进度，最后一帧 100%；覆盖率看标题。

### P2：可复现与可审计

1. 结果带 `tle_sha256`、`catalog_sha256`、`profile_policy_version`；`plan.json` 内嵌 `tle_snapshot`（NORAD、epoch、OMM）。
2. `satellite_table` 补齐 `sensor_class / resolution_m / swath_km`，与报告中的卫星表一致。
3. 云量记录采样点数量、阈值、丢弃窗口数；逐窗口云量值仍在补。
4. 报告首屏补最大相邻过境间隔，避免把跨天并集误读成单景。

## 5. 用 33f46 举例

旧结果（未加太阳/仰角门禁）：

- 目标面积 80%，task1，72h，2 颗星，`81.7163%`，`proven_optimal`。
- 两次过境：JILIN 11-06 22:20（夜间，光学不可用）、SUPERVIEW 11-09 11:34（白天，但成像区云量预报 100%）。
- 最大瞬时 73.4% / 6.9%，间隔约 61 小时；城市平均时间覆盖 0.0937%，同时覆盖 0%。
- 结论：**81.7% 是 72h 并集，不是可执行单景；不能直接下发。**

加 P0 规则重算同一配置：

- 太阳高度过滤检查 8281 个窗口，丢弃 5822 个；云量 9 点采样丢弃 2315 个。
- 结果：`feasible=false`，选中 2 颗，达标面积 **15.0%**。
- 说明：原来的 81.7% 主要来自夜间/云量不可用窗口；加门禁后不成立。

## 6. 假设与误差

- TLE/SGP4 沿轨误差约 1 km/天；过境时间约 ±1 分钟。
- 5 km 网格、边界格面积不规则，覆盖率对网格对齐敏感。
- 沿轨半角固定 60°，是场景假设，会放大条带长度。
- 云量是 Open-Meteo 预报，不是成像时刻实测；72h 外预报不稳定。
- 覆盖率是几何估计，不是辐射/云判读结果；不能用于亚米级规划。

## 7. 术语

- **过境/访问窗口**：卫星能被目标看见的一段时间。
- **单格时间覆盖率**：某格被覆盖时长占窗口的比例。
- **累计面积覆盖/并集**：窗口内至少被看过一次的面积占比。
- **达标面积**：达到时间阈值（或其他目标）的面积占比。
- **最大瞬时覆盖**：某一时刻的最大覆盖面积占比。
- **MRT/ART**：最大/平均重访间隔。
- **薄弱区/未覆盖连通片**：未达标网格连成的一片区域。
